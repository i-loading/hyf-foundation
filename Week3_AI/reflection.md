# Reflection

1. What are 3 new things you learned from AI in this task?

   I learned how to structure a simple portfolio page using HTML, CSS, and JavaScript. I also learned how to ask AI for specific design changes, like centering content or making a page responsive. Finally, I learned that AI can help speed up the process, but I still need to review and adjust the code to make sure it matches my goal.

2. Where did you have to tweak or correct Copilot’s suggestions to suit your needs?

   I had to adjust the styling to match the assignment requirements, especially the centered heading, custom font, and background color. I also changed the button behavior so it changed the background to a random color in a simple and reliable way. The final code needed a few small edits to keep the page clean and responsive.

3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

   Using Copilot to generate code is helpful when I want a quick solution or a starting point. Using it as a learning partner is more useful because it helps me understand why the code works and how to improve it. In the first case, I might copy the answer; in the second, I can ask questions, test ideas, and learn from the explanations. That makes it much more valuable for long-term learning.

4. What are 3 risks of relying too much on AI tools when learning at HackYourFuture?

   One risk is that students may copy code without understanding it, which can make it harder to learn programming concepts properly. Another risk is that AI suggestions may be incorrect or incomplete, so students might build bad habits if they do not check their work carefully. A third risk is that learners may become too dependent on AI and stop practicing problem-solving, debugging, and critical thinking on their own.
