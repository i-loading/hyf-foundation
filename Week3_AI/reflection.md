# Reflection

1. What are 3 new things you learned from AI in this task?

I learned how to build a simple page. I also learned how to ask AI for specific changes. And I knew that AI can speed things up, but I still have to check the code and change it so it fits what I want.

2. Where did you have to tweak or correct Copilot's suggestions to suit your needs?

Copilot's styling didn't fit the assignment and my personal taste, so I had to adjust it. I also changed how the button works so it sets a random background color. The final code still needed a few small edits to keep the page clean and responsive.

3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

When I want a quick solution or a starting point, Copilot is helpful for generating code. It's more useful as a learning partner, because it helps me understand why the code works and how to improve it. If I only generate code, I might just copy the answer. If I use it to learn, I can ask questions and learn from the explanations. The second way is the one that I can actually learn from.

4. What are 3 risks of relying too much on AI tools when learning at HackYourFuture?

First, I could copy code without understanding it, and then it would be harder to learn programming. Second, AI answers can be wrong or incomplete, so if I don't check my work carefully, I could ruin the project. Third, I might depend on AI so much that I stop practicing problem-solving, debugging and thinking things through on my own.
